# Списание времени

Это пошаговая инструкция для списания времени в Jira.

1. Перейдите в соответствующую задачу.

2. Нажмите на кнопку **+** для добавления времени.

3. Заполните поля, указанные на рисунке.

4. После заполнения полей нажмите на кнопку **Работа**.

# **Как включить и использовать спринты в проекте?** *(для РП)*

**1. Включение функции**

* Раздел «Проекты» → выберите проект → «Редактировать проект» → вкладка «Настройки».
* Найдите блок «Спринты» и переведите переключатель «Включить работу с задачами по спринтам» в положение «Включено».
* Нажмите «Обновить проект».

**2. Работа со спринтами**

* В проекте появится новая вкладка *«Спринты».*
* Добавляйте задачи из бэклога в текущий спринт.
* При закрытии спринта невыполненные задачи можно автоматически перенести в новый.
* Следите за прогрессом с помощью диаграммы сжигания задач (burn down chart).
